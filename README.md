# brisa.uy

Fuente de código para Brisa.uy

El propósito de este sitio es compartir historias y aventuras sobre la
navegación de un pequeño velero soltando las olas, viajando por doquier, cuyo
destino final es Uruguay.


## Desarollo

The site is hosted on GitHub Pages.

Maintain the Gemfile according to [About GitHub Pages and Jekyll][about].
For cookbook documentation see [Set up site with Jekyll][ghJk].

[about]: https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll/about-github-pages-and-jekyll
[ghJk]: https://docs.github.com/en/pages/setting-up-a-github-pages-site-with-jekyll

Maintain the version of Ruby [currently in use by GitHub pages][versions].
A mi me gusta [rbenv][rbenv].

[versions]: https://pages.github.com/versions.json
[rbenv]: https://rbenv.org/

The [Jekyll documentation][jdoc] also has information about use with GitHub pages.
[jdoc]: https://jekyllrb.com/docs/github-pages/

Use the script, `script/dev.sh` to serve the site locally while writing.
